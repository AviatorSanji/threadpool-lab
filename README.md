# 线程池学习项目

结合 search-service-calc-price 的新旧线程池，从浅入深练习 Java 并发。

## 学习方式

每次先讲一个概念，再给一个小任务，由你亲手写代码。检查代码、解释运行过程之后，再进入下一步。

使用 IDEA 打开本项目，项目 JDK 选择 21。后续练习直接通过 main 方法运行。

## 学习顺序

1. 定义任务：Callable 的泛型返回值与 call 方法。
2. 直接调用任务：创建对象，在 main 中调用 call。
3. 提交任务：创建线程池，学习 submit。
4. 获取结果：学习 Future 和 get，区分提交与等待。
5. 多任务并发：线程复用、队列、批次等待。
6. 池参数和拒绝策略：对照旧算价池、日志池与新配置。
7. 异常、超时、中断与取消。
8. 请求上下文：ThreadLocal、绑定、复制、恢复和清理。
9. 任务包装、日志收集与合并：对照迁移后的 Provider、Handler 和执行门面。

## 当前练习

在 src/main/java 中新建包 lab.practice，新建 MyPriceTask 类，实现 Callable<Integer>。

在 call 方法里定义原价 10000 分、优惠 1000 分，返回原价减去优惠。先完成任务定义，再学习如何执行它。

练习代码由你编写，指导和检查在对话中逐步进行。
